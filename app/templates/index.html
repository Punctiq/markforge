Developer API

Convert documents to clean Markdown from your own tools.

Use the MarkForge API to upload DOCX, PDF, ODT or DOC files and receive Markdown, ZIP packages with figures, token usage and quality reports. The browser UI uses the same endpoint documented here.

DOCX PDF ODT DOC Markdown ZIP + figures AI quality report
POST /api/v1/convert

Convert one document

Send a multipart form request with a file and conversion options. For automation, use output_format=zip. For web preview or custom clients, use output_format=both.

Form fields

  • file — required document upload.
  • ai_cleanup — true or false.
  • ai_cleanup_mode — safe, balanced or aggressive.
  • output_format — zip, markdown or both.

Output modes

  • zip — binary ZIP download with Markdown, figures and reports.
  • markdown — JSON response with Markdown preview only.
  • both — JSON response with Markdown preview and base64 ZIP.

curl example — ZIP download

curl -X POST http://127.0.0.1:5000/api/v1/convert \
  -F "file=@CEB-HLD.docx" \
  -F "ai_cleanup=true" \
  -F "ai_cleanup_mode=safe" \
  -F "output_format=zip" \
  --output CEB-HLD_markforge.zip

curl example — JSON preview + ZIP base64

curl -X POST http://127.0.0.1:5000/api/v1/convert \
  -F "file=@CEB-HLD.docx" \
  -F "ai_cleanup=true" \
  -F "ai_cleanup_mode=balanced" \
  -F "output_format=both"

GET /api/v1/ai/status

Read AI configuration status

Returns provider, model, supported modes and whether an API key is configured. The API key itself is never exposed.

AI behavior

When ai_cleanup=false, MarkForge runs deterministic conversion only. No LLM call is made, no AI audit is generated and no tokens are consumed.
